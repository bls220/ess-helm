# Added

Add support for Kubernetes Gateway API as an alternative to Ingress for managing external access to ESS Community components. Users can now configure HTTPRoute resources alongside or instead of Ingress resources by specifying `gateway.host` and `gateway.className` values. This provides a more powerful and flexible routing model for clusters running Gateway API controllers such as NGINX Gateway, Envoy Gateway, or others.

## Supported for

- Synapse
- Element Web
- Element Admin
- Matrix Authentication Service
- Matrix RTC
- Hookshot
- Well-known delegation service

## Features

- Dual support: Use Ingress, Gateway API, or both simultaneously
- Global and per-component Gateway API configuration
- TLS certificate management via Secret references
- Annotation support for Gateway API customization
- Controller-agnostic HTTPRoute templates
